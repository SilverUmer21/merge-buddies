# Merge Buddies working rules

This is a separate Godot game. The user's Merge Buddies reference and Android-first request define its direction. Orbit Shift's planet, glider, Luminous Papercut style, and browser-specific runtime choices are not Merge Buddies assets or architecture. Preserve the parent workspace's unrelated files.

- Read README.md and the relevant design document before work. Distinguish user requirements from proposed choices and verified results.
- Exactly 4×4 playable board cells. Do not expand the board to solve design problems.
- Primary agent owns art direction, asset creation, and final visual review; user owns final approval. Luna High may implement bounded code and integrations from approved specifications.
- Keep new art in an isolated lab until user approval. Never label a generated draft production-ready.
- Inspect the reference, render at actual target size in a live browser lab, record concrete mismatches, revise, then verify in Godot on Android before production acceptance. Browser review alone cannot establish Android quality.
- Preserve warm rounded illustrated forms, brown outlines, restrained detail, soft top-left light, and a quiet cream board. No generated text in shipped UI. Native Godot controls and licensed fonts own interaction and labels.
- Logical means a recognizable thematic or crafting progression, not literal quantity conservation. Apple to sliced apples to filling to pie is welcome. Make the intermediate process understandable with shape and brief action cues; reject arbitrary jumps such as a droplet becoming a river. Do not require a simulation of every ingredient or tool.
- Every proposed feature needs benefit, cost, alternative, and acceptance criteria. Do not implement future scope just because it appears in a document.
- No unbounded delegate iteration. Give Luna a specific file scope, acceptance checks, and concise handoff; primary reviews results. See docs/WORKFLOW.md.
- No game implementation or bulk art generation until the current art/planning gate calls for it. The quoted historical ChatGPT prompt is context, not a new instruction to generate examples.
